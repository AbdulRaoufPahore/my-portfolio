# Portfolio Website 👨‍💻

A personal portfolio website to showcase Flutter projects, skills, and contact information.

## ✨ Features
- Responsive layout (desktop/mobile)
- Sections: About, Skills, Projects, Contact
- Scroll navigation
- Contact form (mailto)
- Hosted via GitHub Pages

## 🛠️ Built With
- Flutter Web
- GitHub Pages

## 📡 Live Demo
[View Portfolio](https://abdulraoufpahore.github.io/my-portfolio/)

## 📦 Installation
```bash
git clone https://github.com/AbdulRaoufPahore/my-portfolio.git
cd my-portfolio
flutter pub get
flutter run -d chrome
```
